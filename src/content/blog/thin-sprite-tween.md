카드에 커서를 올리면 오른쪽 위에 작은 엠블럼이 떠오르고, 9프레임으로 움직여요. 엠블럼을 두 개 만들었는데 결과가 갈렸습니다.

| 엠블럼 | 보간 결과 |
| :--- | :--- |
| 아케이드 캐비닛 | 9프레임이 깔끔하게 나옴 |
| 네온 크로스헤어 | 프레임마다 획이 통째로 사라지고 모양이 제각각 |

캐비닛은 덩어리가 크고 속이 찬 그림이고, 크로스헤어는 가늘고 빈 곳이 많아요. 가늘고 빈 그림은 모델이 붙잡을 데가 없어서, 재생하면 움직인다기보다 깜빡이는 것처럼 보입니다.

## 대칭이면 밀면 돼요

크로스헤어는 두 포즈가 같은 중심을 두고 대칭이고, 바깥 조각이 안으로 모이기만 했어요. 그러면 조각을 방향별로 묶어서 실측한 거리만큼 정수 픽셀로 밀면 됩니다. 정수라서 리샘플링이 없고 도트가 뭉개지지 않아요. 중심부만 두 포즈를 알파로 교차시켰습니다.

> 방향을 나눌 때 기준을 캔버스 한가운데로 잡으면 안 돼요. 그림이 1px만 아래로 치우쳐 있어도 가로팔이 "왼쪽아래 대각선"으로 분류돼서 엉뚱한 방향으로 움직입니다. 그림 자신의 무게중심을 쓰고, 2.5px쯤 데드존을 두세요.

## 재생은 시트 한 장과 steps()로

프레임마다 `<img>`를 겹치는 대신, 가로로 이어 붙인 시트 한 장을 배경으로 깔고 `background-position-x`만 움직여요.

```css
.emblem {
  background-image: url('/art/emblem-aimbooster.png');
  animation: play 900ms steps(9, jump-none) infinite alternate;
}
```

`alternate`라서 끝까지 갔다가 되감아 돌아와요. 시작과 끝이 같은 그림이니 이음매가 생기지 않습니다.

`jump-none`을 줘야 0%와 100%를 둘 다 밟아요. 그냥 `steps(9)`로 두면 마지막 프레임을 건너뜁니다.

멈출 때는 `animation`을 끄지 않고 `animation-play-state: paused`만 바꿔요. 껐다 켜면 매번 0번 프레임으로 튀는데, 재생 상태만 바꾸면 멈췄던 프레임에서 그대로 이어집니다. 터치 화면에서는 호버가 아예 일어나지 않으니 `@media (hover: none)`에서는 계속 돌려 둬요.

## 포즈는 한 번에 주문하세요

포즈 넷을 한 번에 주문하면 후보 16장이 같은 화풍으로 나와요. 따로따로 뽑으면 선 굵기나 채도가 어긋나서, 나란히 놓으면 다른 사람이 그린 것처럼 보입니다.

> 같은 색 위에 같은 색을 얹으면 묻혀요 (분홍 카드 위 분홍 크로스헤어). 짧은 검정 `drop-shadow`를 두 겹 주면 도트 윤곽을 따라 테두리가 생겨서 배경과 떨어져 보입니다.

## 애니메이터는 한 변이 256px까지예요

`width × height × frame_count ≤ 524288` 제한도 같이 걸려요. 그래서 움직이는 키아트는 400×248 대신 256×160으로 새로 뽑았어요.

큰 이미지를 base64로 넘기려다 실패하기도 했어요. 9~18k자짜리 문자열은 도구 인자로 넘기는 도중에 깨집니다. 생성 결과가 URL로 올라가 있다면 그 URL을 그대로 넘기세요. base64를 만지지 않고 넘길 방법은 그것뿐이었어요.
